Imported model transform

Rotations apply to the source mesh after up-axis conversion (X, then Y, then Z). X/Y pivot sets the fixed turntable axis. Zero Z offset places the lowest vertex at ground level. Uniform fit preserves proportions.

02 · Direction

Angles are world-space rotations around vertical Z. At 0°, the asset's forward vector is +Y. Blue/cyan face markers denote the defined FRONT.

Directional reference sheet
FRAME 00

Fixed-centre flipbook

Only the object rotates. The camera, world origin, canvas and ground pivot stay locked. Use Play or the frame slider to spot jumps between directions.

The orange crosshair marks the same ground anchor in every frame; the dashed vertical line tracks the pivot. Onion skin reveals how the preceding frame compares.

Use the import transform controls to specify source up axis, rotate around X/Y/Z, preserve proportions or stretch, set pivot and adjust offsets. GLB node transforms and material textures are not yet interpreted by this lightweight canvas renderer. Local forward is +Y after orientation.

Classic projection: screen X = (world X − world Y) × scale; screen Y = (world X + world Y) × scale / 2 − world Z × scale. True-isometric option uses different vertical factors. The pivot is fixed at (frame width/2, frame height × anchorY%). Each model turns around its vertical Z axis, and the camera never moves.
