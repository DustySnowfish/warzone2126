# Incoming branding and artwork

Upload logos, icons, key art, footage, colour lists and fonts here (GitHub: Add file > Upload files),
then mention it in the chat. File names: `slot<number>_<what>_v<version>.<ext>`, for example
`slot1_logo_v2.svg`. The slots, formats and licence rules are in the project doc
art/branding-guide.md. Files are moved to `branding/sources` once they are built into the game.
